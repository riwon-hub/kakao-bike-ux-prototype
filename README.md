# 카카오 T 바이크 UX 프로토타입

카카오바이크 UX/UI 리디자인 과제의 사용성 테스트용 인터랙티브 웹 프로토타입입니다.

- [실행 중인 프로토타입](https://kakao-bike-ux-prototype.fabledpansy32.chatgpt.site/)
- [원본 Figma](https://www.figma.com/design/GcrdmUlRyhXBAv8W7V7nXr?node-id=908-9027)

## 실행하기

Python 3가 설치된 컴퓨터에서 저장소 폴더를 열고 다음을 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다. 설치할 패키지나 별도 빌드 과정은 없습니다. 3D 배경이 모듈을 사용하므로 `index.html`을 파일로 직접 여는 대신 위 서버로 실행해 주세요.

## 화면 및 시나리오

확정된 **보라색 그라데이션** 화면을 사용합니다. 별도의 화면 스타일 선택은 없습니다.

주행 시나리오는 다음 두 가지입니다.

- **정상 주행**: 목적지까지 이동하고 정상 반납합니다.
- **서비스 불가 구역 · 상단 경고**: 경로를 벗어나 회색 구역에 진입하면 상단 카드가 점멸합니다.

서비스 불가 구역 진입만으로 과태료 안내가 열리지 않습니다. 해당 구역에서 **이용 종료**를 눌렀을 때만 20,000원 안내가 열립니다. **반납 구역까지 길 안내**를 선택하고 정상 구역에 돌아오면 경고가 해제됩니다.

전체 흐름: 홈 → 검색 → 반납 지역 선택 → 바이크 선택·찜 또는 QR → 주행 → 도착 → 반납 사진 확인 → 모의 결제 → 반납 완료.

PC에서는 한국 시내 자전거도로의 3D 배경이 지도 경로와 함께 이동·회전합니다. 기본 정상 주행은 약 28초이며, 일시정지와 도착 시 멈춥니다. 모바일에서는 프로토타입 화면을 중심으로 표시합니다.

## 수정할 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조, 테스트 설정, 지도·카드 요소 |
| `style.css` | 레이아웃, 색상, 경고 점멸 등 애니메이션 |
| `app.js` | 검색, 바이크 선택, 주행·요금·경고·반납 상태 |
| `ride-background.js` | Three.js 도시 배경과 주행 시점 |
| `assets/` | 캐릭터, Figma 이미지·아이콘, Three.js 모듈 |

지도와 배경은 `ride-progress` 이벤트로 경로·거리·현재 위치·방향을 공유합니다. 주행 경로를 바꿀 때는 `app.js`의 `normalRoute`, `deviationRoute`, `recoveryWaypoints`를 함께 확인해 주세요.

수정 후에는 브라우저를 새로고침합니다. 캐시가 남으면 강력 새로고침을 사용하거나 `index.html`의 CSS·JS 주소 뒤 버전 문자열을 갱신합니다.

## 함께 편집하기

저장소의 편집 권한을 받은 사람은 GitHub에서 파일의 연필 버튼 또는 키보드 `.`로 웹 편집기를 열어 수정할 수 있습니다. 큰 변경은 새 브랜치에서 작업한 뒤 Pull Request를 만들어 검토하는 방식을 권장합니다.

수정 전후에 정상 반납, 서비스 불가 구역 상단 점멸 경고, 재안내와 사진 다시 찍기를 확인해 주세요. JavaScript 문법은 다음으로 확인할 수 있습니다.

```sh
node --check app.js
node --input-type=module --check < ride-background.js
```

GitHub에 반영한 변경은 현재 공유 사이트에 자동 배포되지 않습니다. GitHub 저장소는 공동 편집용 원본이며, 공유 사이트에 반영하려면 별도 배포가 필요합니다.
